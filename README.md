# 🕌 أوقات الصلاة — Prayer Times Website

A simple, fast, Arabic (RTL) single-page website that shows daily Islamic prayer times for any Arab city.

Type a city name → get autocomplete suggestions → pick a city → see Fajr, Sunrise, Dhuhr, Asr, Maghrib, and Isha times for today.

Default city on load: **Constantine, Algeria (Constantine, DZ)**.

No build step. No backend. No API keys to pay for. Just open `index.html` in a browser.

---

## ✨ Features

- **Live prayer times** for today, fetched per city
- **City autocomplete search** in Arabic / Latin script, restricted to Arab countries
- **Debounced search** (300ms) so we don't spam the API while typing
- **Stale-request cancellation** with `AbortController` — old slow responses never overwrite newer ones
- **Search button + Enter key + click suggestion** all work
- **Responsive RTL UI**: 2 columns on mobile → 3 on tablet → 6 on desktop
- **Arabic typography** with Thamaneya / Thmanyah Serif Display + Inter fallback
- **Graceful errors**: keeps last times on screen, shows `تعذر تحديث الأوقات، حاول مجددا` on failure

## 🔌 APIs Used

This project uses **2 free public HTTP APIs**. No secret keys in headers — everything is a simple `GET` with `fetch()`.

### 1. AlAdhan API — Prayer Times (main data source)

- **Docs:** https://aladhan.com/prayer-times-api
- **Endpoint used:** `GET https://api.aladhan.com/v1/timingsByAddress/{DD-MM-YYYY}?address={CITY},{COUNTRY_CODE}`
- **Auth:** none required
- **Example built by the app:**
  ```
  https://api.aladhan.com/v1/timingsByAddress/22-09-2026?address=Constantine%2C+DZ
  ```
- **What we send:** `address` = `"Name, CountryCode"` (e.g. `Constantine, DZ`). Date in path is generated by `getTodayFormatted()` as `DD-MM-YYYY`.
- **What we get back (simplified):**
  ```json
  {
    "code": 200,
    "status": "OK",
    "data": {
      "timings": {
        "Fajr": "04:03 (CET)",
        "Sunrise": "06:15 (CET)",
        "Dhuhr": "12:37 (CET)",
        "Asr": "16:05 (CET)",
        "Maghrib": "18:59 (CET)",
        "Isha": "20:20 (CET)",
        "Imsak": "...",
        "Midnight": "..."
      },
      "date": {
        "gregorian": { "date": "22-09-2026" },
        "hijri": { "date": "...", "month": {...}, "year": "..." }
      }
    }
  }
  ```
- **How we use it (`Logic.js:193-242`):**
  - Check `data.code === 200`, else throw.
  - Map only 6 keys via `PRAYER_MAP`: `Fajr→time1, Sunrise→time2, Dhuhr→time3, Asr→time4, Maghrib→time5, Isha→time6`.
  - Strip timezone suffix: `rawTime.split(' ')[0]` → `"04:03 (CET)"` becomes `"04:03"`.
  - Reformat Gregorian date `"DD-MM-YYYY"` → `"YYYY - MM - DD"` for the header.
  - On error: `console.error` + show Arabic error message in `#prayer-date`, keep old times visible.

> Note: AlAdhan auto-resolves plain text addresses, so even if the user types free text without clicking a suggestion, the search button still works by passing the raw string as `address`.

### 2. GeoNames API — City Autocomplete (search suggestions)

- **Docs:** https://www.geonames.org/export/geonames-search.html
- **Endpoint used:** `GET https://secure.geonames.org/searchJSON?name_startsWith={QUERY}&maxRows=5&username=abdo&featureClass=P&country=DZ&country=EG&...`
- **Auth:** `username=abdo` query param (free GeoNames account; rate-limited on free tier).
- **Example built by the app:**
  ```
  https://secure.geonames.org/searchJSON?name_startsWith=Constant&maxRows=5&username=abdo&featureClass=P&country=DZ&country=EG&country=SA...
  ```
- **Query params explained:**
  | Param | Value in app | Meaning |
  |---|---|---|
  | `name_startsWith` | user input | prefix match on place name |
  | `maxRows` | `5` (`MAX_SUGGESTIONS`) | max suggestions in dropdown |
  | `username` | `abdo` (`GEONAMES_USERNAME`) | GeoNames account |
  | `featureClass` | `P` | only populated places (cities/towns/villages) |
  | `country` (repeated) | 22 codes | whitelist filter — see below |
- **Country whitelist (`CONFIG.ARAB_COUNTRY_CODES`):** `DZ, EG, SA, AE, MA, TN, IQ, JO, LB, KW, QA, OM, BH, LY, SD, SY, YE, PS, MR, SO, DJ, KM` — suggestions outside the Arab world are excluded.
- **What we get back (simplified):**
  ```json
  {
    "geonames": [
      { "name": "Constantine", "countryCode": "DZ", "countryName": "Algeria", "lat": "36.36", "lng": "6.61" }
    ]
  }
  ```
- **How we use it (`Logic.js:60-162`):**
  - Only fire when `query.length >= 2` (`MIN_QUERY_LENGTH`).
  - Debounce 300ms (`DEBOUNCE_DELAY_MS`) via `clearTimeout` + `setTimeout` so fast typing = 1 request.
  - Abort previous request with `AbortController` before starting a new one; ignore `AbortError` silently.
  - On `data.status` (GeoNames error wrapper) → throw.
  - `renderSuggestions()` builds `<li data-name data-country>` items as `Name, CountryName`; empty result hides the dropdown.
  - Click on `<li>` → fills input as `Name, CODE`, saves `selectedCity = {name, countryCode}`, hides dropdown, calls `loadPrayerTimes(selectedCity)`.
  - Click outside `#searchbar` hides the dropdown.

## ⚙️ Configuration (`Logic.js:12-24`)

```js
const CONFIG = {
  ARAB_COUNTRY_CODES: [...22 codes...],
  GEONAMES_USERNAME: 'abdo',  // ← change to your own GeoNames username if rate-limited
  MAX_SUGGESTIONS: 5,
  MIN_QUERY_LENGTH: 2,
  DEBOUNCE_DELAY_MS: 300,
  DEFAULT_CITY: 'Constantine',
  DEFAULT_COUNTRY: 'DZ',
};
```

To use your own GeoNames account: sign up at https://www.geonames.org/login, enable free web services, then replace `GEONAMES_USERNAME`.

## 🚀 How to Run

1. Clone / download this folder.
2. Make sure you have internet (Tailwind CDN, Font Awesome, Google Fonts, and both APIs need it).
3. Open `index.html` directly in a browser:
   - Double-click it, or
   - `Right click → Open with → Chrome/Edge/Firefox`, or
   - Serve it locally: `npx serve .` / `python -m http.server` then visit `http://localhost:8000/index.html`.
4. That's it — prayer times for Constantine load automatically.

### How to Use

1. Click the search box (`ابحث عن مدينتك` = "Search your city").
2. Type at least 2 letters (e.g. `وهران`, `Cairo`, `Jeddah`).
3. Click a suggestion **or** press Enter / click 🔍.
4. The big city name, date, and 6 time cards update.

## ⚠️ Known Limitations

- `api.js` is dead code (deprecated duplicate of `Logic.js`) — safe to delete.
- `claudehtml.html` is an unused draft — safe to delete.
- GeoNames free tier is rate-limited; heavy use with `username=abdo` may return `status` errors.
- AlAdhan `timingsByAddress` uses address geocoding — ambiguous city names without country code may resolve to the wrong place. Picking a suggestion (which includes country code) is more accurate than free typing.
- Times are for the device's "today"; no Hijri date display, no calculation-method selector, no next-prayer countdown yet.
- Tailwind browser CDN + Font Awesome kit require internet; the page won't style correctly offline.
